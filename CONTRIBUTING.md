# Contributing

Thanks for helping make ServiceM8 MCP Server better. Small, focused changes are easiest to review.

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Fork the repo and make your change.
3. Run `npm install && npm run build && npm test`. All tests must pass.
4. Open a pull request that says what changed and why.

By contributing you agree your work is shared under the MIT license.
